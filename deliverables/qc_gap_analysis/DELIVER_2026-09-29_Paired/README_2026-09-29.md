# Paired Certificate of Quality + internal Certificate of Analysis — 29.09.2026

Two-page files, one per batch: **page 1 the certificate of quality, page 2 the internal certificate of
analysis for that same batch.** 152 certificates — Tranches 1, 2 and 3, initial release and retest.

## Folders
- `Retest/` — the retest certificates (T1, T2, T3). Archived as `CoQ_iCoA_Retest_pairs_2026-09-29.zip`.
- `Initial/` — the initial-release certificates (T1, T2, T3). Archived as `CoQ_iCoA_Initial_pairs_2026-09-29.zip`.
- `CoQ_iCoA_code_map_2026-09-29.tsv` / `.md` — the CoQ document code and its internal-certificate code,
  in document-number order.

## Where each page comes from (each matched to the batch, never only to the code)
- **Certificate of quality (all)** — the current print of the register's pages, house fonts embedded.
  Tranches 1 and 2 are the **frozen pages, byte-for-byte as sent to the customer** (they keep the sent
  footer line and the single-row Section 03); Tranche 3 carries the widened fades of 28.09.
- **Internal certificate, Tranche 3** — the current Tranche-3 delivery.
- **Internal certificate, Tranche 1/2 retest** — the **sent owner-format certificates of 24.09**, each
  matched to its lot by batch, rendered to PDF unchanged (specification reference `…_v.03`, as sent).
- **Internal certificate, Tranche 1/2 initial** — regenerated in the current owner format from the
  register; the initial internal certificates were never issued to the customer, so there is no sent
  version to keep (`…_v.01`, as the register states).

Every pairing is checked so the internal certificate's batch equals the certificate of quality's batch.
