Certificate of Quality issuance schedule

Every CoQ the company owes, in the order it is to be issued — the retired QCCoA 001 replacements first, then the remaining batches, then the retest reissues by tranche. Each certificate carries one checkbox per specification row: the value, the laboratory that produced it, and what is still missing.

Codes run CoQ-PP-year-NNNN, allocated in date order with the sequence restarting each year. The code belongs to the document, so a retest reissue takes a new code and names the certificate it supersedes.

Outsourced re-analysis register

Rows no in-house certificate can close. Microbiological purity, mycotoxins, heavy metals and the pesticide panel are methods the company does not run, so each of these needs an accredited laboratory — with a lead time and a cost the iCoA register does not carry.

Compiled from the extracted certificate corpus. Document codes are allocated strictly in date order — the waves order the work, the codes order the documents — so no code in the register runs backwards in time. The issue date is the date of the testing campaign the certificate reports; a backlog certificate signed later can be re-dated to its signing day, which moves its code into that year. Each certificate is compiled as the evidence stood at its own campaign, so a release certificate states what was known then rather than what a later retest found. Nothing here decides conformity.
