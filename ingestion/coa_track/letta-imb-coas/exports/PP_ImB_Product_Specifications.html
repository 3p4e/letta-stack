  • Loss on drying is ≤ 12.0 % per the current Ph. Eur. 11.5 Cannabis flos 07/2024:3028. Certificates issued before that monograph took effect carry ≤ 10.00 %; the current monograph governs.
  • Bile-tolerant gram-negative bacteria is specified at the Ph. Eur. 5.1.8 category C limit of ≤ 10⁴ CFU/g. The Purely Plant in-house CoA applies a tighter < 10² CFU/g and some IPH reports print ≤ 10²; the tighter practice is not specified here but is not prohibited by it.
  • Mycotoxins are specified as all three parameters. Batches assayed before the Farmahem 197-series retests carry total aflatoxins only; on those the other two are recorded as not tested rather than left blank.
  • Pesticides are specified as a conformity statement, not an analyte list. A value is stated only where there is an actual finding.
