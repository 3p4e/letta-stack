# assets/logo/PP_Leaf_T2.svg

The QCSP 001 specifications reference the Purely Plant mark as `../assets/logo/PP_Leaf_T2.svg`,
which is how the issued documents in `PROD_SPEC/` reference it — the specifications sit one
directory below `assets/`, and the path resolves there.

The mark itself is not in this repository, so the header box renders blank here. Drop
`PP_Leaf_T2.svg` into this directory, or place `exports/house_specs/*.html` beside the
`assets/` folder already in Drive, and it appears. The box is a fixed 168 × 62 either way,
so nothing else on the page moves.
